# Hollywoo After Dark

An unofficial fan site for *BoJack Horseman*, built with Next.js 15, TypeScript,
Tailwind CSS v4 and Framer Motion. All artwork and copy are original; this is a
non-commercial tribute with no affiliation to the show's creators or rights
holders.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run start` – serve the production build
- `npm run lint` – type-check with `tsc`

## Structure

- `src/app` – layout, global styles, home page
- `src/components` – Nav, Hero, Seasons, Cast, Themes, Footer
- `src/data/show.ts` – season and cast content
